# Gaussian blur

**Effect type:** `blur`

`blur` applies a Gaussian blur to the surface from the selected input.

## Properties

| Property | Type | Default | Options or shape |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | `true`, `false` |
| `showOriginal` | `ShowOriginal` | `none` | `none`, `front`, `back` |
| `blurRadius` | `number` | `8` | Non-negative number |

A positive blur radius adds paint margins for auto-crop.
