# Changelog

All notable changes to this project will be documented in this file.

The format is inspired by Keep a Changelog and this project follows Semantic Versioning.

## [1.0.0] - 2026-09-01

Initial public release of captioncat.

### Included

- Reusable caption design and rendering engine
- Command-line interface
- Bundled caption presets and font assets
- captioncat Preset Studio
- GitHub Pages deployment for Preset Studio

### Requirements

- Node.js 22 or later
